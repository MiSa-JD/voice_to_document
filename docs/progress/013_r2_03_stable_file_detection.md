# R2-03 — 안정 파일 판정

- 기록 번호: 013
- 상태: 완료
- 관련 로드맵: R2-03
- 완료 시각: 2026-08-25T05:34:23Z

## 작업한 내용

- 입력 루트를 재귀 검색하는 `StabilityTracker`를 구현했다.
- 대소문자를 구분하지 않는 `.m4a` 일반 파일만 후보로 삼았다.
- symlink, Syncthing 임시 이름, part/partial/download/tmp 이름과 다른 확장자를 제외했다.
- 크기와 nanosecond mtime이 설정 시간 동안 바뀌지 않은 파일만 안정 파일로 반환하도록 했다.
- 파일이 사라지면 과거 관찰 상태를 제거해 재등장 파일이 즉시 안정으로 오판되지 않게 했다.
- clock을 주입해 테스트가 실제 안정화 시간을 기다리지 않도록 했다.

## 남은 문제와 결정

- 프로세스 재시작 시 메모리 관찰 상태는 복구하지 않고 파일을 새로 한 번 더 관찰한다. 미완성 파일을 조기에 처리하지 않는 안전한 기본값이다.
- 실제 오디오 유효성은 다음 ffprobe 단계에서 별도로 확인한다.
