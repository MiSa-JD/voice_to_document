## 작업한 내용

- transcript의 외부 LLM API 전송을 허용하는 현재 정책을 기록했다.
- 정책과 공급자 결정의 소유자를 사용자로 정했다.
- 실제 공급자, 모델, base URL, API 키는 R7 진입 전에 확정하도록 기한을 기록했다.
- R1~R3는 fake document 어댑터만 사용하고 실제 transcript를 외부로 전송하지 않도록 정했다.
- LLM_API_KEY는 `.env` 또는 프로세스 환경으로만 전달하고 로그와 artifact에서 제외하도록 정했다.

## 검증 결과

- 환경 결정 문서에서 외부 전송 허용 상태, 소유자, 결정 기한, fake 모드 제한, 키 관리 원칙을 확인했다.
- 문서와 README에서 일반적인 실제 API 키 패턴이 검출되지 않았다.

## 남은 문제와 결정

- 외부 LLM 공급자와 모델은 아직 미결정이며 R7 진입 전 사용자가 확정해야 한다.
- 외부 전송을 실제로 활성화하기 전 README와 UI에 데이터 전송 안내를 추가해야 한다.
