1. 휴대폰 녹음 -> 녹음된걸 syncthing으로 공유 -> 공유된 m4a 파일 확인 -> 텍스트 뽑아낸 적이 있을 경우 생략, 아닐 경우 STT -> 분류 -> 요약된적 있을 경우 생략, 아닐 경우 요약
2. STT는 WhisperX + large-v3 + pyannote
  - pyannote: 화자 분리
    - pyannote에서 분리된 화자는 Speaker_00 과 같은 형태로 수집됨. 따라서 사용자가 해당 화자가 누구인지 정의해줘야 함
      - 분리된 화자는 녹음파일과 함께 격리되고 각 화자가 누구인지 분류를 기다림 
      - 처음에 사용자는 해당 음성을 직접 분류하지만, 데이터가 쌓이고 similarity가 특정 threshold를 넘겨 분류가 가능할 경우 자동 분류하게함 
      - 화자의 분리나 분류가 잘못됐을 경우 사용자가 화자를 직접 수정할 수 있어야 함
3. STT를 거친 뒤 글의 전체 내용을 보고 분류해야하며 분류는 큰 범주에서 골라야 함
  - 강의, 일상 대화, 회의, 게임 목록 등
4. 분류가 완료된 글은 사용자의 요청에 의해서, 또는 특정 분류일 경우 자동으로 요약을 진행함
  - 요약본은 `해당범주/요약/`에 기록됨
5. 화자 분리본 저장 위치, STT된 글 저장 위치, 녹음 파일 위치는 모두 .env로 관리할 수 있어야 함
6. Docker Compose로 손쉽게 up down을 할 수 있어야 함
